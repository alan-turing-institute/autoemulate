# Bayesian Model Comparison: SIR vs. SEIR

This case study demonstrates how to perform Bayesian Model Comparison using `AutoEmulate`. It evaluates two competing epidemiological models—the standard SIR model and the extended SEIR model—against synthetic data to compute the Bayesian Evidence (Marginal Likelihood) and calculate the Bayes Factor.

## How to Run

1. **Install Dependencies:**
   Navigate to this directory and install the required packages (it is recommended to do this within a virtual environment):
   
       pip install .

2. **Launch the Notebook:**
   Start your Jupyter environment and run the case study:
   
       jupyter notebook sir_seir.ipynb
